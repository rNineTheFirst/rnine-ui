# Type

| Font | For |
| --- | --- |
| **Fraunces** (variable, SOFT 100, WONK 1) | Headings, the shop's name, numbers that matter; its italic is the hand in notes and journals |
| **Literata** | Running text and UI |
| **Courier Prime** | Labels, eyebrows, dates, table heads: uppercase, tracked 0.13em |
| **Pinyon Script** | A signature or a flourish, never running text |

All self-hosted through Fontsource, under the SIL Open Font License
(`@rnine/ninefold/fonts.css`). Use the type roles, not raw sizes:
`@include r9.type(h2)`. Display and h1 to h2 sizes are fluid.
